Sega Dreamcast, 1998

One Hitachi SH-4 at 200 MHz, 16 MB of RAM and a dial-up modem.

  • RE4 Dreamcast test build 27.2

    Resident Evil 4 on the Dreamcast, built from the GameCube game’s own recovered code and drawn by a native Dreamcast renderer. The current test build runs from New Game into the castle on Disc 2.

    C++ and Python

  • dc-qalink

    QA and telemetry for Dreamcast games over the console’s own modem. A game reports metrics once a second, and a PC or a coding agent can send commands back, at no cost to frame time.

    C and Python

  • Halo Dreamcast Edition online

    The online services for Halo Dreamcast Edition: the master server, the official server patch for OpenCE, and a browser test tool on Cloudflare Workers.

    Go, C and JavaScript dce-directory-server opence-dce-server dce-web-tool

Sega Saturn, 1994

Two Hitachi SH-2 CPUs at 28.6 MHz and 2 MB of work RAM.

  • AvP Saturn beta 0.1.2

    Capcom’s 1994 Alien vs. Predator arcade game running natively on the Saturn, for one or two players with all four characters, music and sound. Tested on a real Saturn.

    C, Python and MAME Lua Play it in a browser

  • cps2saturn

    The porting kit behind AvP Saturn, for moving Capcom CPS2 arcade games to native Saturn code. It pairs a phase-gated playbook and a Claude Code skill for each area of the work with game-neutral Python and MAME Lua tools.

    Python, C and Lua

  • F-Zero X Saturn workbench

    Groundwork for a native Saturn port of F-Zero X. It imports the Mute City course from a verified ROM, rebuilds the track math in fixed point, and runs the same C core on the Saturn and in a browser.

    C, Python and WebAssembly Open the workbench

  • SH2ZAM

    Fixed-point math for the Saturn’s SH-2 CPUs, with Q16.16 arithmetic, vectors, matrices and quaternions. An independent adaptation of SH4ZAM, the Dreamcast math library by Falco Girgis and contributors.

    C Open the math lab
